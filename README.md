# KROK STREET 👟

KROK STREET is a modern streetwear e-commerce website designed for people who love urban fashion, sneakers, and casual clothing. The project features a dark interface, vibrant colors, and a clean, minimalist design that creates a stylish and comfortable shopping experience.

## ✨ Features

- 🏠 Modern homepage with a promotional hero section.
- 🛍️ Product catalog with stylish product cards.
- 🏷️ Product filtering by categories.
- 🔍 Product search functionality.
- ↕️ Product sorting options.
- 📦 Filter products by availability.
- 🛒 Shopping cart with a modal window.
- 📱 Responsive design for different screen sizes.
- 🎨 Smooth animations and interactive elements.
- 🚚 Animated announcement bar with delivery and exchange information.

## 🛠️ Technologies

- **HTML5** — website structure.
- **SCSS / CSS3** — styling, layout, and responsive design.
- **JavaScript** — interactive elements and website functionality.
- **Git** — version control.

## 🎨 Design

The website uses a dark background combined with bright orange accents and colorful product cards. Its minimalist layout, modern typography, and interactive elements create a distinctive streetwear aesthetic.
